# ✊ Rock Paper Scissors

A simple interactive **Rock Paper Scissors game** built using HTML, CSS and Vanilla JavaScript.

This project started as a basic console-based game and was later transformed into a browser-based game with a graphical user interface (UI).

The main objective was to practise JavaScript fundamentals and understand how to make HTML elements interactive using DOM manipulation.

## 🎮 Features

- Interactive UI: Play using clickable Rock, Paper and Scissors buttons.

- Random Computer Choices: The computer randomly selects one of the three options.

- Winner Detection: JavaScript determines the winner of each round.

- Live Scorecard: Tracks user wins, computer wins and draws.

- Dynamic Results: Displays both players' choices and the winner of each round.

- Next Round Functionality: Move to the next round using the Next button.

- Button State Management: Enables and disables buttons to control the game flow and prevent unwanted interactions.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript 

No external libraries or frameworks were used.

## 📸 How to Play

1. Open the game in your browser.
2. Select Rock, Paper or Scissors.
3. Click the **Confirm** button to submit your choice.
4. The computer randomly generates its choice.
5. The game determines the winner and updates the scorecard.
6. Continue playing after pressing next and try to beat the computer!

## 🧠 What I Learned

Building this project helped me understand how different JavaScript concepts work together.

Some important concepts I explored:

- DOM manipulation using `querySelector()`.
- Event handling using `addEventListener()`.
- Updating webpage content using `textContent`.
- Generating random numbers using `Math.random()` and `Math.floor()`.
- Using conditional statements to determine the winner.
- Managing game scores using JavaScript variables.
- Dynamically controlling button states using the `disabled` property.
- Connecting HTML, CSS and JavaScript to build an interactive application.
